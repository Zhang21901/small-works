Quick guide · 三个工具都可在浏览器中使用。界面右上角可切换 English / 中文。

01 / LedgerLeaf · 每周收款复盘

  1. 选择 My business 工作区，或在「工作区与备份」里创建新工作区。Demo Studio 是虚构数据。
  2. 新增账单，或导入 CSV。必须填写账单编号、客户、账单原始总额和到期日。累计已付金额单独填写；日期格式为 YYYY-MM-DD，金额格式为 1234.56。
  3. 在导入预览里核对更新数量。相同「编号 + 客户 + 币种」会更新金额与日期，并保留付款承诺及跟进历史；未出现在导入文件里的账单不会被删除或自动结清。
  4. 选择复盘日期与币种。不同币种分别统计，不会使用未经确认的汇率合并。
  5. 点「查看」记录部分付款、争议、暂停和客户承诺。有效承诺和未来跟进日期会抑制提醒。
  6. 准备邮件，核实实际到账后自行发送。复制或打开邮件不会标记已联系；实际联系后，再点「我已联系」。
  7. 导出周报 HTML，打开后按 Ctrl+P 保存为 PDF。周报包含备注，分享前检查其中的内容。
  8. 导出 JSON 完整备份。CSV 是账单数据列表；恢复跟进历史请使用 JSON。

English: Start in My business → add or map a CSV → check balances → review the follow-up queue → prepare a draft → send it yourself → record contact → export the weekly report and JSON backup.

02 / ScopeKit · 增项报价与确认

  1. 先填写原先约定的范围，再描述这次新增工作。工具不会替你判断合同边界。
  2. 逐项填写工时与单价；设置预留工作量、税率、预付款比例和增加的日历天数。
  3. 明确不包含的工作，保存报价，再导出 HTML / 打印 PDF。
  4. 复制邮件，由客户通过邮件或你已有的签署流程确认。
  5. 收到真实回复后，在确认记录里写下依据，再手动改为「已确认」。这是记录状态，不是电子签名。

English: Record the original scope → estimate the change → export the change order → obtain written confirmation separately → record the reference. Status is entered manually; no signature or identity verification is collected.

03 / CareProof · 网站维护月报

  1. 创建客户和报告月份，按实际情况记录工作与完成状态。新工作默认「计划中」。
  2. 扫描器由项目所有者在本机终端运行：
    node tools/site-audit.mjs --url https://example.com --out artifacts/site-check.json
  3. 导入生成的 JSON。网站来源必须与报告一致；检查时间会原样保留。
  4. 补充下月计划和需要客户确认的内容，保存月报，再导出文件或复制交付邮件。

扫描只做网页 GET 请求，检查初始 HTML，最多抽查 8 个站内链接。它不测全天在线率，不运行页面脚本，不验证表单邮件投递、登录、支付、备份或安全性。404 的 robots.txt / sitemap.xml 被标成待复核，不直接判为网站故障。

English: Record real work → run the included local scanner → import its JSON → add next steps → export a client report. Scans are timestamped snapshots, not continuous monitoring.

数据保存与版本说明 / Data & version

所有业务数据保存在当前浏览器的本地存储中。应用没有客户数据上传接口、账号系统或云端备份。切换浏览器、清除缓存数据、换电脑、改变网站地址或使用隐私模式都可能导致记录不可用。每次工作结束后，请下载 JSON 备份并妥善保存。

恢复操作会替换该工具的全部已保存记录，请先备份。多个标签页同时编辑时，如果保存被阻止，请刷新读取最新数据。

当前版本面向小批量单人使用，尚未接入自动发送、支付、订阅、团队协作或电子签名。打开邮箱和点击你填写的外部证据链接会离开本工具。网页托管商可能记录普通访问日志。

Local storage only; no cloud backup, accounts, payment processing or automatic sending. Export backups regularly. A restore replaces saved data for that tool. The hosting provider may keep ordinary web access logs.
